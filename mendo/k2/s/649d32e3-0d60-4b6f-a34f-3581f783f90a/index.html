Green axes = the two dominant traits. Paradigms in play: structural (line + axis + KPI grid) · abstract (flat, dark, geometric) · emotional (up/down carried by color temperature). No named external styles.

1 Intent

A night-over-night velocity tracker whose entire job is to answer one question — up or down? — before the viewer reads a word. The six axes resolved on two dominant signals: bold hierarchy and premium-serious emotion. Coherence enforced from there: bold → one hero (the velocity number and its line), everything else demoted; premium → generous whitespace around the hero and a refined type scale; abstract → flat surfaces, no skeuomorphic depth. No contradictions among the axes (calm/energetic-style clashes absent). It extends the console’s existing dark-flat chart language rather than inventing a second look.

2 System rules

Spacing

Base unit 4px. Scale: 4 / 8 / 12 / 16 / 24 / 32 / 48. Generous padding around the hero (24–32), tight inside data chips (8–12). Ratio of hero-whitespace to data-whitespace ~2:1 — the “premium” breathing room.

Typography

UI sans: Helvetica Neue / system. Numbers & times: mono (Consolas). Scale 11 / 12 / 13 / 20 / 48 — the hero velocity number is the 48px mono, everything else ≤20. Weights 400 (body), 700 (labels/KPIs), 800 (hero). Line-height 1.15 on the hero, 1.55 on prose.

Color

Extends the console palette; described by role, not decoration:

Temperature: cool base, warm only for “behind.” Projected/tentative = accent at 55% + dashed. Text contrast AA+ on the base surface.

Density

Balanced: one hero line + ≤4 KPI chips + a single “tonight” detail card per viewport. Never a dashboard wall — the line must dominate.

Depth

Flat (abstract paradigm). No drop shadows. Elevation read only from 1px borders and a small surface-lightness delta (#0b0f14 → #0e141b → #11161d).

3 Component behavior

Velocity number (the hero)

~48px mono, colored by trend (green up / amber flat / red down), with a small ▲/▼ delta vs last night beside it. It is the largest thing on the page by 2×.

Trend line

2px stroke, node dot at each night. Closed nights = solid; tonight = a dashed segment to a hollow node with a translucent best/worst band; a dotted horizontal benchmark reference. Slope carries the whole message.

KPI chips

Small bordered pills — mono number, dim uppercase label (points · net hours · residuals · Δ vs last). Border 1px #1c2530, radius 8, no fill beyond the base surface.

Cards

Surface #0e141b, 1px #1c2530 border, 10px radius, flat. Left-accent border only when the card carries a verdict (green up / amber watch).

Tables (night log)

Compact rows ~34px, mono times, header tron-blue 10px uppercase, no zebra (flat), 1px row separators.

Navigation

Minimal — a horizontal night selector / legend strip; the active night marked with the accent underline. No chrome that competes with the hero.

4 Interaction

Transitions

200–300ms, ease-out. On load: the line draws left→right, the band fades in behind it, the hero number counts up to its value. Nothing bounces (restrained expression).

Feedback

Hover a night node → tooltip with that night’s points / net hours / residuals. Focus rings in the accent. The projected marker pulses subtly (it’s live and will move). Empty / no-data → a dim “no nights logged yet” state, never a broken axis.
