Modifier re-run of the 22:00 system · paired (Opus + Fable5) · supersedes v1 as the build spec

v1 argued. KISS just rules. Same stance, less mechanism — six rules a builder holds in their head, eleven CSS variables, and the two things that can’t be simplified away because they’re standing orders: a machine claim can never look like a verified fact, and the page is marked INTERNAL ONLY.

Axes (unchanged — KISS cuts mechanism, not stance): serious · dense · abstract · bold · silent · restrained. Paradigms: structural + emotional-on-state-only, abstract base.

The system — 6 rules

  1. Host surfaces, flat, 1px borders. No shadows, no motion, no own nav. Blue = navigation only, never state.
  2. Hue = state, nothing else. red confirmed blocker · amber claimed/open · green operator-verified only.
  3. Claims are hollow, facts are solid, green needs a human. Machine claim = dashed border, no fill, no ID. Fact = filled, mono ID. No code path runs from feed data to green.
  4. Mono for every data atom (IDs, dates, site codes). 12px floor on anything that means something.
  5. Triage numbers 28px at top; cards below, blocker-first. No horizontal scroll.
  6. 44px touch targets. Sticky INTERNAL ONLY strip. An unmarked feed refuses to render.

Rule 3, shown

claimed done machine said it — unproven    ■ EXC-001 recorded fact    ✓ verified you tapped it

Kill the colour and it still reads: hollow vs solid, no-ID vs ID. That’s the whole O-7 mechanism — one property, not a taxonomy.
