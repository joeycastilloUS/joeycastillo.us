# ---- THE DEMAND -----------------------------------------------------------

demand:

  D1  Every NPS-detractor email is answered, and the reply goes DIRECTLY to the
      guest — the guest is the requester, no side conversation. Only mail to the
      NPS address is answered; nothing else the box receives.

  D2  A guest who receives a recovery reply gets ONE single-use promo code —
      never reused, never double-issued. The exactly-once guarantee lives in the
      code service, not in the AI.

  D3  Any sign of food-borne illness stops the machine: the guest is NEVER
      auto-replied and NEVER sent a code — the case goes to a human. When in
      doubt, escalate. An illness auto-reply is the one unforgivable send.

  D4  The reply speaks in Mendo's voice — short and informal, not long and formal.

  D5  Every response CCs the District Operator / Store, automatically.

  D6  Nothing runs against a real guest until jc arms it. Sandbox until then;
      jc is final approval.

# ---- THE WORDS ------------------------------------------------------------

words illness-procedure:
  | If the message shows ANY sign of food-borne illness — nausea, vomiting,
  | diarrhea, hospital, "got sick", "food poisoning", or any paraphrase, in
  | any language — ALWAYS escalate to a human. Do NOT reply. Never send a code.

words tone:
  | Mendo's voice: short, warm, informal. A few sentences, not a formal letter.

# ---- CONFIG  (declared intent values the enactment sets) ------------------

config:
  channel:         email                      # D1 — inbound email, guest is the requester
  scope.address:   nps@                         # D1 — dedicated NPS reply-to; agent answers only this
  code.source:     external-https-endpoint      # D2 — issues + burns a one-time code
  code.once:       required                      # D2 — exactly-once lives in the code service
  escalation:      human-group                   # D3 — illness routes here; no auto-reply, no code
  tone.style:      informal                      # D4
  tone.length:     short                         # D4
  cc.on-response:  district-operator, store      # D5 — plain trigger
  arm:             disarmed                      # D6 — jc arms prod
