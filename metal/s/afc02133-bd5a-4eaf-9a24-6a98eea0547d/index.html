Startup — Firestore was never the problem

Every console open pulled ~260 MB out of Firestore to emit 13 MB. The atb_ocr batch read fetched each document whole, including the saved crop and legacy thumb JPEGs (~99 KB per doc across ~2,700 docs) — and the response then threw the crops away. We paid for every byte we discarded.

Worse: Installation issued ~4,000 lookups that return zero documents, in 14 sequential round trips. The operator confirmed why in one line: “you don’t scan for install.”
