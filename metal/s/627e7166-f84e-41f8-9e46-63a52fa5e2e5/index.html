✓ Built & verified — unit test green on the REAL CONTRACT shape (6 cases), slot proven over the wire, clean compile.

What was built

  • manifold/slot_chat.c + .h — the chat source slot. Takes the landing store’s RawRecord JSONL and emits one [ts] user: text line per valid record. Optional channel filter. Best-effort: a malformed line is skipped, never fails the gather.
  • Reuses slack_record_parse() (slack-bridge/importer/slack_record.c) — the existing C99 Track B CONTRACT parser. The field contract stays in exactly one place; the slot adds only normalization.
  • POST /slot/chat wired into the Manifold — the slot’s own verify surface over the wire (body = landing JSONL, ?channel= optional).
  • manifold/test_slot_chat.c — 6 assertions on the real CONTRACT shape (incl. \" and — escape decode, channel filter, malformed-skip, invalid-drop).

How it fits the design

A slot is a small C99 reader that turns one source’s items into normalized {text}. This is slot #1. The Bus that dispatches to slots per {source,id}, and the Firestore fetch that feeds the slot in production, are separate items — here the slot is proven standalone and over the wire against real record shapes. “New source later = one slot + one pin” starts being true now.
