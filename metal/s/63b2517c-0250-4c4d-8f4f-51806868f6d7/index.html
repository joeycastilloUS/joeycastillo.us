New Default Device Order

One fixed sequence for every site — Bread → Salad → Expo → Digital Expo → Terminals → Printers. Each station keeps its Start · Finish · Printer trio together, so the eye tracks a lane top-to-bottom instead of hunting. Ingest and HerdServe break out into their own infrastructure band, and HerdServe carries its WiFi / port right on the row. This is also the order applied when you sort by device.
