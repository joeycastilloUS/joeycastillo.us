What the mockups lock

  • Three lanes are visually distinct: push (green) / drift (red) / Admin Center (amber) — the operator sees at a glance what Argus does vs what stays a click.
  • Every push shows the response ID + rollback inline — no blind writes.
  • The four no-API knobs are honest: labeled Admin Center, deep-linked, verified by read/behavior — never faked as pushed.
  • Arm/disarm is one switch, prod double-gated — the operator owns go-live from Argus.
