Demonstration · Kick-off

The same workflow, built two ways.

Automated NPS-detractor recovery with a food-illness safety gate — built two ways on the same account, against the same tickets. One arm uses Zendesk's in-box AI; the other, Argus, is fully managed AI. Today we run both and show how each one gets it done.

The intent, plainly

A guest gives a low NPS score. Recover them — a short, warm apology and a $10 code to make it right. But if that guest is reporting they got sick, there is no code and no automated reply — the ticket goes straight to a human. That safety line is absolute: the machine never answers a sick guest.

The two lanes

RUN FIRST
Lane B

Zendesk in-box AI

Copilot intelligent triage + the AI agent — the vendor path.
  • The AI classifies the ticket and decides.
  • Reads the message, predicts intent + sentiment, drives the reply.
  • The AI + triggers are configured inside Zendesk.
  • Still needs external code — coupon-code generation + District Operator email lookup. Zendesk can’t compute a secret code or look up data it doesn’t hold.
RUN SECOND
Lane A

Argus — Fully Managed AI

The same demands, met with fully managed AI.
  • Two Gemini models today — expandable to any available model as needed.
  • We choose and route the model for the job.
  • ~$0.0003 per ticket.
