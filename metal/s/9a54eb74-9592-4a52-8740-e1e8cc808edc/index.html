How to arm

  1. From Argus (preferred, once shipped): the Arm/Disarm control on each S2②/S4/S5 row → /zendesk/ai-reply-toggle.
  2. From Zendesk (fallback): Admin Center → Objects and rules → Triggers → open the argus: trigger → toggle Active.
  3. Arm one, send one matching test ticket, verify the expected outcome, then arm the next. Never arm all four at once.
  4. Emergency stop: disarm the S5 recovery trigger (and/or the S4 gate) — that is the live reply path. The GUARD full-kill toggles only the Ultimate AI reply, which is already OFF permanently, so it is NOT the emergency stop for this design.
