~go — Export a POS switch map (asleep devices included)

BUILT + TESTED   DEPLOY VERIFYING   Paired: Opus driver, Fable navigator reviewed the diff (Rule 1, serial). One additive read-only bridge endpoint + one export button in the Network SSID view. Existing functionality untouched.

The ask

"Add an option to Network SSID so I can export a network map. Do not remove current functionality. The network map shows the POS switch only — port number, description, and MAC address of every port. And because printers go to sleep, show the devices on that port even if they haven't been awake."

Why the existing views couldn't do it

The Network / port views run on /meraki/portmap, which fetches network clients at Meraki's default 24-hour window — the on-screen stamp literally says "connected-now only." A printer asleep longer than 24h simply isn't in that data. So this couldn't be a UI-only change; the data itself had to come from a wider window.

What was built

1 — Bridge: GET /meraki/switch-map (additive, read-only)

  • Filters devices to the POS switch only — switches whose Meraki name contains POS (override with ?match=).
  • Pulls clients at the 31-day window (Meraki's max), not 24h — so a device seen anytime in the last month still reports its port + MAC even while asleep now.
  • Returns every port: number, description, VLAN, PoE, live status, and the device(s) mapped to it (MAC, IP, name, manufacturer, last-seen, status). Empty ports render too.
  • Pagination fix (navigator catch): the 31-day list can exceed one 1000-row page, and asleep devices sort into the tail (ordered by last-seen) — exactly what a single page drops. Added ClientsPagedAsync that follows Meraki's Link: rel=next cursor across pages. The plain ClientsAsync (used by portmap) is untouched.

2 — Web: "Export POS switch map" button in the Network SSID view

  • One button at the top of the Wi-Fi/SSID section (existing SSID list follows, unchanged).
  • Click → fetches /meraki/switch-map → opens a printable map (new window) with a Download CSV link (self-contained data: URI) and a Print button.
  • Asleep devices are highlighted (amber + "● asleep"), so the sleeping printers are visible, not hidden.
