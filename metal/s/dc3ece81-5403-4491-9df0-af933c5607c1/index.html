5 · What remains before the first live simulation

Two small, deliberate steps — both in the sandbox, both operator-approved:

  • Seed the sandbox code vault with test "We're Sorry" codes (IMSORRYTEST…) so a simulated reply claims a real code.
  • Field-id alignment for macros that set custom ticket fields — sandbox custom-field ids differ from production; Argus names the exact fields to map (no silent copy).

Every step is previewed and operator-approved before anything sends. Guest-recovery for detractors is the only automated path; food-safety concerns are detection-and-escalation only, never auto-replied.
