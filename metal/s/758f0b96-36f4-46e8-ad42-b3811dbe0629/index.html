Two things prod testing caught (Rule 14)

1. --allow-unauthenticated silently failed in the build — the service deployed with zero IAM bindings (Cloud Build SA couldn’t set the allUsers invoker). Fixed by adding allUsers→run.invoker explicitly, matching the other bridges.
2. Authorization: Bearer collides with Cloud Run’s IAM — Cloud Run intercepts any Bearer token as a Google identity token and 401s before the app. Switched the machine gate to a custom header X-Manifold-Token, which passes straight through. Both found only by testing from the real vantage — a local pass would have hidden them.
