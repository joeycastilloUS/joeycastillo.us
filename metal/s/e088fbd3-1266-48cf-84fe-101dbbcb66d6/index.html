What the action must do

  1. On a clean-detractor recovery (after ai_reply_ok), call the bridge: POST https://zendesk-bridge-d5vc4tye3a-uw.a.run.app/zendesk/promo-claim with body { "ticket_id": <this ticket>, "env": "sandbox-b" }.
  2. Authenticate via a bearer connection carrying BRIDGE_TOKEN (never paste the token into a public field — it lives in the connection).
  3. Take the returned code and write it into the SorryCodes ticket field — field id 50360163920916.
  4. The S5 recovery trigger fires on that field being present and renders the code via {{ticket.ticket_field_50360163920916}} in the fixed Zora template. Exactly-once by construction (same ticket → same code; recovery_sent guard).
