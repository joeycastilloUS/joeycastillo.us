What kills this if missed

  1. macKey not normalized. POS returns 1c:ee:c9:13:24:a3, printers return 0013412DFA88. Without NormMac at ingest the Meraki join silently returns zero for one entire device class — and nothing errors.
  2. lastSyncedAt / deviceUptimeMillis left in the hash. They change on every poll, so 100% of snapshots read as drift, the event log becomes noise, and the skip optimization never fires.
  3. menus written to Firestore. Hard failure at 3.3× the 1 MiB document limit — and the field-value limit blocks the {json: raw} escape too.
  4. deviceCount used as fleet size. Overstates ~3×. Toast never purges decommissioned records — 14 of 20 devices at Brentwood are ghosts, one stale 402 days.
