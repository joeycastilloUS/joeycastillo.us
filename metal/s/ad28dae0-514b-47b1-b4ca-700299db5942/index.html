The defect

Yesterday’s ~u put the Enable/Disable button into the STATUS cell as a bare text node followed by the button. Nothing established a common start position, so the button’s x moved with the width of the word in front of it — Disabled (8 chars), Connected (9), Disconnected (12). Down a 28-port switch that reads as a ragged edge.

The fix

The PoE column two cells over had already solved this exact problem, and the fix reuses its idiom rather than inventing one: .poest{display:inline-block;min-width:40px} is what keeps its Disable/Enable button in line regardless of the ⚡ bolt. Same move for STATUS.
+  .swptbl .stw{display:inline-block;min-width:92px;}

-  "<td class='"+(conn?"st-conn":"st-disc")+"'>"+esc(p.status||"")+portBtn+"</td>"
+  "<td class='"+(conn?"st-conn":"st-disc")+" nw'><span class='stw'>"+esc(p.status||"")+"</span>"+portBtn+"</td>"
Why 92px: “Disconnected” is the widest string the grid can render and measures ~84px at the table’s .86rem, so 92px clears it before the button’s own 6px margin — without widening the column, which the button already pushed past 92px anyway. Why nw: the word and its button must never wrap onto two lines on a narrow viewport; that reuses the existing .nw utility rather than adding a rule.

Test — ~t

The complaint was visual, so the verification is visual. A page was built from the CSS rules pulled verbatim out of index.html (8 of 8 found — table, td, th, .st-conn, .st-disc, .nw, .poetog,.porttog, .swptbl .stw; none retyped, so it cannot pass against a copy that has drifted) and rendered in headless Chrome.

The trap that was avoided. .st-conn and .st-disc are colour classes shared by four consumers — the port grid, the 24h history table, a client list, and the export stylesheet. Putting min-width on those classes directly would have silently reflowed three tables nobody asked about. A new class used at exactly one site cannot. Worth noting the .swptbl scope is belt, not braces: the history table is a <tr> inside the same .swptbl table, so the descendant selector would reach it — what actually guarantees isolation is that .stw appears nowhere else, which the grep proves.
