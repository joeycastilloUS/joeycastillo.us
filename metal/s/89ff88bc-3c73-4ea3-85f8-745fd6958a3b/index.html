Step 2 — Respond

Serves D1 · CONFIRM

What

Publish the email AI agent and make it fire only on NPS-detractor mail. Because hello@ is shared, the discriminator is body content, not the address.

Where — the auto-reply trigger (per DIA .si)

Admin Center → AI agents - Advanced: publish the email agent on Arm B's brand. Then Objects and rules → Triggers:

Conditions (meet ALL):
  Ticket        is       Created
  Received at   is       support@guestrelationstestv2.zendesk.com
  Comment text  contains "NPS Score"   (or "Guest Experience Alert")

NOT "Received at = nps@" - there is no nps@.

D1 — corrected discriminator (per DIA .si respond, pattern form)

Publish the email AI agent; auto-reply trigger = Ticket Is Created AND Received at = support@guestrelationstestv2 AND Comment text contains "NPS Score" (or "Guest Experience Alert") — the body-content discriminator, since hello@ is shared. A detractor NPS email (body has "NPS Score") gets a public AI reply to the guest; all other mail on that address stays silent.

Verify

A test email whose body carries "NPS Score" triggers the agent; ordinary mail on that address does not. Reply lands to the guest as requester (D1: direct to guest, no side conversation).

Status

CONFIRM — agent published + body-content trigger built on Arm B. Comment to flip.
